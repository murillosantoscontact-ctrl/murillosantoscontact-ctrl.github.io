Política de Privacidade e Termos de Uso

A Sara é um assistente pessoal privado, usado só pelo dono. Não tem outros usuários.

Dados acessados: compromissos da agenda (título, data, horário, local) e dados do Spotify (o que toca, playlists), só depois que o dono autoriza e só para atender aos pedidos dele.

Uso: os dados não são vendidos, não são compartilhados para publicidade e não são usados para treinar inteligência artificial. As chaves ficam só no servidor privado da Sara.

Google: o uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Desligar: a qualquer momento na própria Sara (Conexões > Desconectar) ou em myaccount.google.com/permissions.

Termos: ferramenta pessoal, sem garantia, usada por conta e risco do dono.
